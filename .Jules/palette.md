## 2026-03-27 - [Streamlit Dashboard Enhancements]
**Learning:** Adding visual cues for active states in sidebars and formatting raw timestamps significantly reduces cognitive load for users monitoring multi-agent missions.
**Action:** Always use distinct emojis or visual markers for selected items in lists and provide human-readable time formats instead of ISO strings.

## 2026-05-10 - [Navigation and Discoverability Enhancements]
**Learning:** Keyboard shortcuts like 'Esc' for navigation and informative tooltips on buttons with cryptic labels (like emojis) improve both accessibility for power users and clarity for new users.
**Action:** Always provide 'help' tooltips for icon-only or emoji-heavy buttons and implement logical keyboard shortcuts for primary navigation actions.
