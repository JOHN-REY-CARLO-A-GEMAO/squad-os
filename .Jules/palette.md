## 2026-03-27 - [Streamlit Dashboard Enhancements]
**Learning:** Adding visual cues for active states in sidebars and formatting raw timestamps significantly reduces cognitive load for users monitoring multi-agent missions.
**Action:** Always use distinct emojis or visual markers for selected items in lists and provide human-readable time formats instead of ISO strings.

## 2026-04-23 - [Keyboard Navigation & Tooltips]
**Learning:** Adding descriptive `help` tooltips to buttons in Streamlit not only improves accessibility for screen readers but also provides immediate visual feedback for all users. Keyboard shortcuts like `shortcut='Esc'` significantly speed up repetitive navigation tasks in dashboard-heavy applications.
**Action:** Implement `help` tooltips and keyboard shortcuts for primary navigation elements to ensure a high standard of accessibility and power-user efficiency.
