## 2026-03-27 - [Streamlit Dashboard Enhancements]
**Learning:** Adding visual cues for active states in sidebars and formatting raw timestamps significantly reduces cognitive load for users monitoring multi-agent missions.
**Action:** Always use distinct emojis or visual markers for selected items in lists and provide human-readable time formats instead of ISO strings.

## 2026-05-12 - [Accessibility and Navigation Polish]
**Learning:** Adding image captions in the gallery and keyboard shortcuts (like Esc for 'Back') significantly improves accessibility for screen readers and power-user efficiency respectively.
**Action:** Always include filenames or descriptive text as captions for visual artifacts and map common navigation buttons to intuitive keyboard shortcuts.
