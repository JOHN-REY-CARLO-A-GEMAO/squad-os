## SkillRegistry Fixes
- **Bug**: Package tools from .sqad couldn't be instantiated by SkillRegistry
  - Root cause 1: Module loaded via `spec_from_file_location` wasn't registered in `sys.modules`, so `importlib.import_module()` couldn't find it
  - Root cause 2: `get_tool()` used wrong module name for package tools (`tech_stack_analyzer` vs `pkg_tech_stack_analyzer`)
  - Root cause 3: Agent tool definitions use bare names (`tech_stack_analyzer`) but registry stored them prefixed (`ai_saas_launch_pipeline.tech_stack_analyzer`)
- **Fixes applied**:
  - `marketplace.py`: Added `sys.modules[spec_name] = module` in `_discover_tools()`
  - `marketplace.py`: Fixed `get_tool()` to use `pkg_` prefix for package tools
  - `marketplace.py`: Added bare-name fallback in `get_tool()` scans for `key.endswith(f".{name}")`
  - `worker.py`: Added package tool discovery loop after hardcoded inventory
  - `marketplace.py`: Replaced all emoji with ASCII equivalents for Windows
