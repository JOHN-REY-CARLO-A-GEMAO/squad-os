## 2026-03-27 - [Streamlit Dashboard Enhancements]
**Learning:** Adding visual cues for active states in sidebars and formatting raw timestamps significantly reduces cognitive load for users monitoring multi-agent missions.
**Action:** Always use distinct emojis or visual markers for selected items in lists and provide human-readable time formats instead of ISO strings.

## 2026-05-06 - [Implicit Constraints Visualization]
**Learning:** For components with hidden system constraints (like file size limits in uploaders), using the 'help' tooltip provides essential guidance without cluttering the primary UI layout.
**Action:** Always accompany file uploaders or complex inputs with tooltips detailing their specific validation limits or expected formats.
