## 2026-03-27 - [Streamlit Dashboard Enhancements]
**Learning:** Adding visual cues for active states in sidebars and formatting raw timestamps significantly reduces cognitive load for users monitoring multi-agent missions.
**Action:** Always use distinct emojis or visual markers for selected items in lists and provide human-readable time formats instead of ISO strings.

## 2026-05-04 - [Accessibility and Navigation Enhancements]
**Learning:** Using 'shortcut="Esc"' in Streamlit buttons provides a familiar and fast escape hatch for power users to navigate back to the main interface. Adding 'help' tooltips to icon-only or multi-project lists reduces ambiguity and helps users understand the destination before clicking.
**Action:** Consistently apply 'shortcut' and 'help' parameters to primary navigation buttons to improve both accessibility and UX speed.
