## 2026-03-27 - [Streamlit Dashboard Enhancements]
**Learning:** Adding visual cues for active states in sidebars and formatting raw timestamps significantly reduces cognitive load for users monitoring multi-agent missions.
**Action:** Always use distinct emojis or visual markers for selected items in lists and provide human-readable time formats instead of ISO strings.

## 2026-04-26 - [Standardized Empty States & Accessibility]
**Learning:** Using 'st.info' with specific icons for empty states (🖼️, 📜, 🧠, ✅) creates a consistent visual language that guides users when data is missing. Adding 'help' tooltips and keyboard shortcuts to primary navigation buttons significantly improves accessibility and efficiency.
**Action:** Replace plain empty state messages with standardized 'st.info' components and always include 'help' and 'shortcut' parameters for key navigation elements in Streamlit.
