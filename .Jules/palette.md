## 2026-03-27 - [Streamlit Dashboard Enhancements]
**Learning:** Adding visual cues for active states in sidebars and formatting raw timestamps significantly reduces cognitive load for users monitoring multi-agent missions.
**Action:** Always use distinct emojis or visual markers for selected items in lists and provide human-readable time formats instead of ISO strings.

## 2026-04-15 - [Dashboard Visual Consistency and Feedback]
**Learning:** Standardizing empty states with `st.info` and relevant icons, along with using `border=True` for key metrics, creates a more professional and guided user experience that reduces "blank slate" anxiety.
**Action:** Replace plain text empty states with semantic informational components and use high-contrast borders for critical performance indicators.
