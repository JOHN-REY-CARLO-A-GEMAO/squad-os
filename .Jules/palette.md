## 2026-03-27 - [Streamlit Dashboard Enhancements]
**Learning:** Adding visual cues for active states in sidebars and formatting raw timestamps significantly reduces cognitive load for users monitoring multi-agent missions.
**Action:** Always use distinct emojis or visual markers for selected items in lists and provide human-readable time formats instead of ISO strings.

## 2026-04-20 - [Standardized Empty States]
**Learning:** Using `st.info` with descriptive icons for empty states instead of plain text or error banners provides a more welcoming and professional UI, clearly signaling that the system is working but has no data to display yet.
**Action:** Replace all plain "no data" text with icon-enriched informational banners to maintain visual consistency and reduce user alarm.
